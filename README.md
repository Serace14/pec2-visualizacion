# PEC 2 · Visualización de datos (UOC)

Sergio Jiménez Frago. Tres visualizaciones interactivas hechas con D3.js:

- `word-cloud/`: nombres más frecuentes de recién nacidos en España, 2024 (INE).
- `gantt/`: calendario de siembra, floración y recolección de 17 cultivos (MAPA, 2014–2016).
- `connected-scatterplot/`: PIB per cápita frente a CO₂ per cápita en España, 1960–2022 (Our World in Data).

Los datos de cada gráfico están en `datos/`. Publicado con GitHub Pages: rama `main`, carpeta raíz.
